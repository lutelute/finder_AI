# FinderAI

**📖 [使い方ガイド（GIF付き）](docs/GUIDE.md)** — 主要機能を実際の画面録画で説明しています。

FinderAIは、ファイル整理とShell・Codex・Claudeを一つのネイティブmacOSウインドウへまとめたワークスペースです。左に場所、中央にファイル一覧、下に開閉・リサイズ可能なTerminalを置きます。標準Finderへ注入・改造・リサイズを行いません。

標準Finder内部へ第三者のTerminalを埋め込む公開APIはありません。別ウインドウをFinderへ重ねる方式も実装済みですが、位置・フォーカス・Spaceの境界を完全には消せません。そのため、幅とライフサイクルが最初から一致する単一ウインドウ構成にしています。旧オーバーレイ版は1.1.0で廃止しました。

## すぐ使う

[最新リリース](https://github.com/lutelute/finder_AI/releases/latest)から`FinderAI.zip`を落とし、`/Applications`へ入れてください。

> **配っているのは v1.2.2 までです。** それ以降は手元でビルドして入れ替える運用にしています（Developer ID証明書を持っていないため）。上に積んである prerelease は自己署名なので、落としても Gatekeeper に止められます。開発中の版を使うなら、下の「開発成果物を直接使う場合」から入れてください。経緯と再開の条件は[リリース手順](docs/RELEASING.md)にあります。

インストール済みの場合:

```bash
open "/Applications/FinderAI.app"
open -a FinderAI ~/Documents/GitHub   # フォルダを指定して開く
```

Finderの右クリック「このアプリケーションで開く」やDockアイコンへのドロップからも渡せます。ファイルを渡すと、その入れ物のフォルダを開いてそのファイルを選んだ状態にします。既定の扱い手にはならないので、フォルダのダブルクリックはこれまでどおりFinderが開きます。渡したフォルダを既に開いているウインドウがあればそれを前に出し、無ければ新しいウインドウで開きます（見ていたウインドウを差し替えることはありません）。

## アップデート

1日に1度バックグラウンドで確認し、新しいバージョンがあれば**黙ってダウンロードして、アプリを終了したときに入れ替わります**。クリックは要りません。`FinderAI`メニューの「アップデートを確認…」でその場で確認・適用もできます。

ただし**いまはフィードが v1.2.2 で止まっている**ので、この経路で新しくなることはありません。手元でビルドして入れ替えてください。

強制終了した場合は入れ替わりません。終了時のインストールは正常終了が前提です。

現在実行中のversion・build・commit・実行場所は設定（`⌘,`）の下部で確認できます。`dist`の開発用コピーや、ディスク上だけが新版になって再起動を待っている状態もここで区別します。

更新はEdDSA署名を検証してからでないと適用しません。本番成果物はさらにDeveloper ID署名、Hardened Runtime、Apple notarization、staple、署名済みappcastを必須にします。ローカル開発版だけはフォルダアクセス許可を維持するための自己署名です。どちらの秘密鍵もリポジトリには入りません。

リリースは`./scripts/release.sh <version> [notes.md]`で行います。テスト、Developer ID署名、notarization、staple、ZIP再検証、Sparkle署名、署名済みappcast、GitHubのdraft検査と公開を一続きで行います。**証明書を取るまでは公開前に停止する**ので、素直に実行しても意図せず公開されることはありません。詳しい準備とGitHub Actionsの秘密情報は[リリース手順](docs/RELEASING.md)にあります。

いまどれが配られていて手元がどれなのかは、`./scripts/check-working-state.sh`の「== 配ったもの ==」で実物から読めます。

開発成果物を直接使う場合:

```bash
open "dist/FinderAI.app"
```

Accessibility権限は不要です。デスクトップ・書類・ダウンロードを初めて開いたときは、macOS標準のフォルダアクセス確認が出る場合があります。

## 画面と操作

- 左サイドバー: ピン留め、よく使う項目、場所、よく使うフォルダ、最近。境界をドラッグして160〜360ptで変更できます。
- 上部: 戻る、進む、親フォルダ、パス欄、再読み込み、新規フォルダ、表示モード、検索。幅が足りないときだけ検索が2段目へ落ちます（検索範囲の「直下／配下」は、探し始めてから出ます）。
- 表示: リスト、カラム、ギャラリー、マップを直接選べます。リストは4列の比較、カラムは階層移動、ギャラリーは大きなアイコンでの探索、マップはグループの重なりを見るためのものです。
- 右クリック: 開く、Finderで表示、名前変更、新規フォルダ、ゴミ箱。
- ドラッグ＆ドロップ: 通常は移動、Optionを押しながらならコピー。同名項目は上書きせず、操作前に拒否します。
- 下部: クリックで移動できるパスバー（現在地と祖先）。右クリックで「パス名をコピー」「“cd” コマンドをコピー」が出ます。`⌥⌘C`は選択中の項目（未選択なら現在フォルダ）のパス名をコピーします。Terminalは`⌘J`または`TERMINAL`で開閉、上端をドラッグして160〜600ptで変更できます。ヘッダーのダブルクリックで「半分 → 最大 → 畳む」と大きさが一段ずつ巡り（`⌘⇧J`も同じ）、畳んでいるときはヘッダーのどこを押しても開きます。
- Terminalの置き場所: 下辺と右辺を選べます。ヘッダーの配置ボタン（`⌘⌥J`でも同じ）で入れ替わり、下辺は280〜720ptの幅で右側に立ちます。横に長い下辺はスクロールバックが数行しか見えないので、ビルド出力やAIセッションのように縦に流れるものは右辺のほうが読めます。高さと幅は別々に覚えるので、行き来してもそれぞれの大きさが戻ってきます。右辺で畳むと34ptの縦ストリップになり、実行中のセッション数だけがアクセント色のバッジで残ります。
- Terminalのホイール: 普通の画面ではスクロールバックを遡ります。tmuxのシェルやclaudeのような全画面のアプリ（alternate screen）の上では、ホイールを`↑``↓`キーとして送りません——送ればスクロールではなくコマンド履歴や前のプロンプトを呼び出す打鍵になるからです。xtermの`DECSET 1007`を立てたアプリにだけ、従来どおり矢印キーを渡します。
- 上部アドレスバーの隣のターミナルアイコンは「“cd” コマンドをコピー」ボタンです。スペース・括弧・クォート入りのパスでもエスケープ済みなので、Terminalに貼ってreturnを押すだけで移動できます（アドレスバーの生テキストをそのまま`cd`に貼ると、zshは`(L)`などをglobとして解釈して失敗します）。

### グループ — フォルダを作らずにまとめる

平らに並んだ146個のリポジトリを、**実体を一つも動かさずに**まとめられます。フォルダを作って中へ移すと、gitのパスもシンボリックリンクもビルドスクリプトのパスも壊れますが、グループはそのフォルダに置いた一枚のJSON（`.finderai-groups.json`）に「どれとどれが同じか」を書くだけで、ファイルシステムには何も起きません。

- 一つの項目が**複数のグループに属してよい**（「ツール開発」であり「Swift」でもある、は普通のこと）
- グループを**入れ子**にできる（`可視化 ∈ 研究`）
- 一覧では見出しとレールで、マップでは島として見えます。**マップでは複数所属が一つの点**になり、島の境界に立ちます
- 定義はフォルダと一緒に動きます。メンバーを直下の名前で持ち、絶対パスを持たないので、別のマシンで開いても生きています

→ **[グループの仕組みとJSONの形](docs/GROUPS.md)**

### サイドバー

| セクション | 内容 |
|---|---|
| ピン留め | `⌃⌘T`で追加・解除。並びは自分で決められます（最大30件） |
| よく使う項目 | **Finderのサイドバー登録をそのまま表示**します。読み取り専用で、Finderで登録すればここにも出ます |
| 場所 | マウント済みのボリューム。抜き差しで自動更新します |
| よく使うフォルダ | 開いた回数の多い順。2回以上開いたものだけが出ます |
| 最近 | 最後に開いた順 |

同じフォルダは一度しか出ません。ピン留めしたものは、よく使う項目や最近には重複表示されません。空のセクションは見出しごと隠れます。

Finderのよく使う項目が読めない場合は、ホーム・デスクトップ・書類・ダウンロードを代わりに表示します。

### キーボード

| キー | 動作 |
|---|---|
| `⌘N` | 新規ウインドウ（現在のフォルダで開きます。設定で「開く先のフォルダ」を決めておくと、そちらを優先します。ウインドウメニューに開いている全ウインドウが並びます） |
| `⌘W` | ウインドウを閉じる |
| `⌘2` / `⌘3` / `⌘4` | リスト／カラム／ギャラリー表示（Finderと同じ割り当て） |

| `⌃⌘S` | 2画面に分割／解除 |
| `⌘L` | 上部のパス欄へフォーカス（全選択。コピーや打ち替えに） |
| `⌘⌥C` | 現在のパスをコピー |
| `Return` / `⌘↓` | 選択項目を開く（フォルダは移動、ファイルは既定アプリ） |
| `Space` / `⌘Y` | クイックルック |
| `⌘I` | 情報を見る（未選択なら現在フォルダ） |
| `⌘D` | 複製 |
| `⌃⌘A` | エイリアスを作成 |
| `⌃⌘T` | サイドバーにピン留め／解除 |
| `⌃⌘E` | このフォルダを画面端に置く／外す |
| `⌘⇧.` | 隠しファイルの表示切替 |
| `⌘F` | 検索欄へフォーカス |
| `⌘[` / `⌘]` / `⌘↑` | 戻る／進む／親フォルダ |
| `⌘Z` / `⌘⇧Z` | 取り消す／やり直す |
| `⌘J` | Terminalの開閉 |
| `⌘⌥J` | Terminalを右／下に移動 |
| `⌘⇧J` | Terminalの大きさを切り替え（半分→最大→畳む） |

| `⌘⇧T` | Terminalセッションの一覧・管理 |

最後のウインドウを閉じてもアプリは終了しません。Terminalセッションが動いたままになるためで、Dockアイコンから開き直せます。終了は`⌘Q`です。

検索中に新規フォルダを作成・改名すると検索を解除し、処理した項目を見失わないようにします。削除は必ず確認後にmacOSのゴミ箱へ移し、完全削除は実装していません。

検索範囲の「直下」は表示中フォルダを即時に絞り込み、「配下」は子孫を再帰検索して起点からの相対パスを表示します。配下検索は打ち直し・範囲変更・フォルダ移動で古い処理を中止し、結果は最大5,000件です。カラム表示中に検索すると一時的にリストへ切り替わり、検索を消すとカラムへ戻ります。

名前変更・移動・コピー・新規フォルダは`⌘Z`で取り消せます。取り消しの副作用も上書きを行わず、作成物の取り消しは削除ではなくゴミ箱へ移します。ゴミ箱操作自体の取り消しはFinderの「戻す」に委ねています。

現在のフォルダは監視しており、他のアプリがファイルを追加・削除・改名すると自動で一覧へ反映します。表示中のフォルダ自体（またはその上位フォルダ）がFinderやシェルで移動・改名された場合は、履歴とウインドウタイトルごと新しい場所へ追従します。削除やゴミ箱行きのときは、残っている最も近い上位フォルダへ退避します。

### 画面端のフォルダ

よく使うフォルダを画面の縁に貼り付けておけます。`⌃⌘E`で今見ているフォルダをタブにすると、画面の右端（表示メニューで左端にも変えられます）に細いタブが並びます。

- タブを押すと中身が開き、もう一度押すと閉じます。設定の「マウスを乗せるだけで開く」を入れると、押さずに開くようになります（通り過ぎただけで開かないよう0.3秒留まってからです）。
- タブの`⌃`クリック（右クリック）でリスト／アイコン表示と並び順（名前・変更日・サイズ、昇順／降順）を変えられます。`⌘`クリックで上の階層が並び、選べばそこを開きます。
- 開いた一覧は矢印キーで動かせます。`↑↓`で選び、`→`かreturnで開き（フォルダは中へ）、`←`で戻り、escで閉じます。キー操作中もFinderAIは前面に出ません。
- **ウインドウと同じファイル操作ができます。** スペースでクイックルック、右クリックから「情報を見る」「Finderで表示」「複製」「エイリアスを作成」「圧縮」「名前を変更」「新規フォルダ」「ゴミ箱に入れる」、`⌘C`／`⌘V`でコピーとペースト、`⌘⌫`でゴミ箱。移動・コピーの規則（同名の拒否、Optionコピー）はウインドウ側とまったく同じ実装を通ります。
- 開いた一覧では、ファイルのダブルクリックが関連アプリ、フォルダのダブルクリックはその場で中へ降ります（`‹`で戻ります）。深い場所へはDockより速く着きます。FinderAIのウインドウで開きたいときは、ヘッダーの「開く」かタブの右クリックです。
- 一覧のファイルはドラッグして他のアプリへ取り出せます。逆に、タブや一覧へドロップすると入ります。移動とOptionコピー、同名の拒否はFinderAI本体と同じ規則です。ドロップ先として受け取れるタブはアクセント色に光ります。
- Terminalセッションが走っているフォルダのタブには小さな青い点が付きます。右クリックの「このフォルダのTerminalを開く」でそのセッションへ直行できます。
- **FinderAIが前面になくても使えます。** 押してもFinderAIは前面に出てきません。他のアプリで作業しながら、端から覗いて閉じるための場所です。
- 置けるのは8個までです。タブの右クリックから外せます。まとめて隠すのは表示メニューの「画面端のフォルダを表示／隠す」で、隠しても登録は残ります。
- 表示メニューの「画面端のフォルダを自動的に隠す」を選ぶと、タブは普段は画面の外へ引っ込み、**画面の縁にカーソルを当てたときだけ滑り出します**。既定はオフ（常に表示）です。隠れているものは思い出せないので、まず見えている状態から始めて、邪魔だと感じたら隠す形にしています。
- 畳んでいるあいだはフォルダを読みません。開いた瞬間に読み、閉じたら捨てます。

Dockにフォルダを入れるのと似ていますが、画面の下端まで往復せずに済みます。

### たくさん開いたときの見分け

ウインドウは20枚まで開けます。同じ名前のフォルダを何枚も開くと、タイトルだけでは区別できなくなるので、

- **重なったときだけ**、タイトルの副題に親フォルダ名が出ます（`logs`が3枚なら「logs — 2026年度」「logs — 査読_IET_界先生」のように）。重ならないときは冗長なので出しません。
- **ウインドウメニュー**に開いている全ウインドウが並びます。目的の場所へはそこから戻れます。
- 画面端のタブから開くときは、すでにそのフォルダを見ているウインドウがあればそれを前面に出します。同じ場所を映したウインドウが増えても見分けがつかなくなるだけなので、新しくは開きません。

### 覚える状態

ウインドウ位置・サイズ、サイドバー幅、表示モード、並べ替え列と昇降順、Terminalの高さ・幅・置き場所（下辺／右辺）と開閉、画面端のフォルダとその左右、隠しファイルの表示、最後に開いていたフォルダを次回起動時に復元します。最後のフォルダはパスで保存し、消えていればホームから開始します。

これとは別に、全ウインドウのフォルダと実行中セッションの構成を常時スナップショットしており、正常終了しなかった次の起動でだけ復元を提案します（[Terminalの節](#クラッシュしても作業を失わないために)参照）。

## Terminal

フォルダを閲覧しただけではプロセスを開始しません。展開後の`Shell`、`Codex`、`Claude`、または`＋`を押したときだけPTYを作ります。

- Shellは`/bin/zsh -l`です。
- Codex／ClaudeはCLIが見つかる場合だけ有効になります。自動インストールしません。
- セッションはフォルダと種類の組で保持します。
- **表示中のShellはフォルダ移動に追従して自分も`cd`します。** 送るのはプロンプトで待機中のときだけで、コマンド実行中・vim等のTUI・打ちかけの入力があるときは何も送りません（打ちかけの行は`^C`で安全に破棄してから移動するため、入力と混ざって誤実行されることはありません）。追従したShellは所属フォルダごと移動し、タブも青のまま付いてきます。
- Claude／Codexには**何があってもcdや文字を送りません**。AIセッションはタブに残り続け、フォルダをいくら移動しても消えません。
- Shellを追従させたくないときは、タブの右クリックで「フォルダ移動に追従（cd）」をオフにします。📌付きのタブになり、その場に留まります。
- タブ帯には表示中の全セッションが常に並びます。いま見ているフォルダ以外のセッションは「Claude · フォルダ名」のように所属フォルダ付きで残ります。移動先のフォルダに自分のセッションがあればそれが前面に出ます。
- **タブは種類ごとの記号と色で見分けます。** Shellは端末、Codexは山括弧、Claudeはきらめきの記号です。記号の色は状態も兼ねていて、いま見ているフォルダで動いていれば青、別の場所なら種類の色、止まっていれば淡色になります。
- **今いるフォルダのセッションが帯の先頭に並びます。** 帯が詰まって後ろが削られるとき、先に消えるのは「よその場所のもの」です。
- **帯が狭くなると段階的に詰めます。** 「名前＋フォルダ」→「名前だけ」→「記号＋2文字」の順です。それでも入らないぶんは「**＋N**」と数で示し、押すとセッション管理（`⌘⇧T`）で選べます。どんなに狭くても、いま見ている1本は必ず帯に残ります。
- **`⌘⌥→`／`⌘⌥←`で前後のセッションへ移れます。** 帯に入り切らず「＋N」に送られたセッションにも、回っていけば届きます。
- **タブの右クリックから名前を付けられます。** 同じフォルダにClaudeを何本も立てたときは、名前がそのままタブの表示になります（種類はツールチップに残ります）。
- **タブをダブルクリックすると、ブラウザがそのセッションの現在地へジャンプします。** シェルで手動`cd`した後でも、カーネルに実際の作業ディレクトリを問い合わせるので正しい場所が開きます（右クリックの「このセッションの場所をブラウザで表示」も同じ）。
- 移動メニューの「Finderの現在地を開く」（⇧⌘F）は逆に、本物のmacOS Finderの最前面ウインドウが表示中のフォルダをFinderAIで開きます（初回にオートメーションの許可を求められます）。
- 移動した先にすでにターミナルやAIが開いている場合は、そのタブとヘッダーのフォルダアイコンがアクセント色になります。「この場所で開いているもの」と「別の場所で動いているもの」が色だけで区別できます。
- セッションはウインドウをまたいで共有します。同じフォルダを2つのウインドウで開くと、どちらにも同じShellが出ます（2つ起動されません）。
- パネルを隠してもセッションは継続します。
- セッションタブの右クリックでは「タブを隠す（実行は継続）」「現在の表示を記録として保存…」「セッションを終了…」を別々に選べます。タブを隠してもPTYやTerminalバッファは破棄されません。
- セッション終了とアプリ終了は、FinderAI自身が開始したPTYだけを対象にし、実行中なら確認します。

### AIに名前と役割を持たせる

タブの右クリック「**名前と役割…**」で、そのAIが何者で何をする係かを決められます。

- **名前**はタブにそのまま出ます。同じフォルダにClaudeを何本も立てても見分けが付きます。空欄にすると種類名（Claude）へ戻ります。
- **役割**は、次にそのフォルダでClaudeを開始したときシステムプロンプトへ足されます（`--append-system-prompt`）。役割はフォルダ×種類の台帳に残るので、一度決めれば同じ場所のClaudeは毎回その役回りで立ち上がります。
- **役割が効くのは起動の瞬間だけです。** 走っている最中に変えても、そのセッションの振る舞いは変わりません（tmuxへ再接続するときもコマンドは渡らないため）。
- 役割を持つタブには`✳︎`が付き、全文はツールチップに出ます。`⌘⇧T`の一覧には「役割」列があり、役割の文言でも検索できます。
- **Codexには役割欄を出しません。** `--append-system-prompt`に相当する公開フラグが無いためです（0.146.0で確認）。効かない指示を書けるように見せるより、出さないほうが正しいと判断しています。名前は付けられます。

### 前回の続きから始める

そのフォルダでAIを動かした記録が台帳にあると、開始ボタンが「**Claudeで前回の続き**」「**Codexで前回の続き**」になり、直近の会話へ戻ります（Claudeは`--continue`、Codexは`resume --last`）。

- tmux永続セッションが生きていればそこへ再接続し、Macの再起動などでtmuxごと消えていれば、会話を引き継いだ新しいセッションが立ち上がります。
- **戻れなかった場合は、その旨を1行断ってから新しい会話を始めます。** セッションが消えて何も起きない、という状態にはなりません。
- まっさらに始めたいときは`＋`メニューを使ってください。続きがあるときは「Claude（新規の会話）」と明示されます。

### クラッシュしても作業を失わないために

3つの独立した仕組みがあります。

- **セッション台帳（常時）**: セッションID、種類、フォルダ、backend、時刻、表示・終了状態を`~/Library/Application Support/FinderAI/session-registry.json`へ原子的に保存します。FinderAI再起動後も管理画面に履歴が残ります。Terminalの内容は保存しません。壊れた台帳は同じ場所へ`session-registry.corrupt-*.json`として隔離し、アプリは空の台帳で起動します。
- **構成の復元**: FinderAIが正常終了しなかった場合、次回起動時に「前回の構成（ウインドウとTerminalセッション）を復元しますか？」と確認します。復元は同じフォルダで同じ構成を作り直すもので、通常セッションのプロセスの中身は戻りません。
- **永続セッション（tmux、既定オフ）**: 設定（`⌘,`）の「セッションを永続化（tmux）」を有効にすると、以降のセッションはtmux内で動きます。FinderAIが落ちても終了してもシェルやClaude/Codexは生き続け、同じフォルダの開始ボタンが「◯◯に再接続」になります。tmuxは自動導入しません（`brew install tmux`）。UIからセッションを閉じたときはtmux側も終了します。
- **出力ログ（既定オフ）**: 設定（`⌘,`）の「出力をログに保存」を有効にすると、以降のセッションの出力を`~/Library/Application Support/FinderAI/session-logs/`へ追記保存します。クラッシュ直前に何が起きていたかを後から読めます。14日で自動削除されます。既定でオフなのはプライバシー方針（Terminal内容を保存しない）を守るためです。

### すべてのセッションを俯瞰する

ドロワーに出るのは「今見ているフォルダ」のセッションだけです。ウインドウを何枚も開いて方々でシェルを起こしたときは、表示メニューの「**Terminalセッションを管理…**」（`⌘⇧T`）からセッションセンターを使ってください。

- アプリ内の全セッション（表示中・バックグラウンド・終了）、再起動前の台帳履歴、tmuxに残っているセッションを1つの表に出します（種類・フォルダ・状態）。履歴だけを選んだ場合は「記録を削除」で台帳から整理できます。FinderAI名義tmuxを起動時・再アクティブ時に照合し、生存中なら再接続、確認済みで見つからなければ「消失」と表示します。tmuxへの問い合わせ自体が失敗した場合は消失扱いにしません。
- 「タブに表示」またはダブルクリックで、隠したセッションを元のTerminalバッファごと戻せます。FinderAIをまたいでtmuxに残ったセッションも同じ操作で再接続します。
- 「記録を保存…」はアプリ内セッションの現在の表示バッファだけを、保存先を確認してテキスト化します。自動保存はしません。
- 「フォルダを開く」はセッションの表示状態を変えず、そのフォルダへだけジャンプします。
- 「選択を終了」「すべて終了」で一括終了できます。永続化を切った後にtmuxへ残ったセッションの掃除もここです。
- FinderAI名義（`finderai-`で始まる名前）以外のtmuxセッションには一覧・終了とも一切触れません。
- **実行中の数には、tmuxで生きているが接続していないぶんも含みます。** アプリを開き直した直後は繋いだものが1つも無いので、これを数えないと「実行中0件」と出て、動いているAIが1つも無いように読めてしまいます。内訳が要るときは「実行中5件（うち3件は未接続）」のように添えます。
- 検索欄は名前・種類・役割・フォルダ・状態を横断し、「実行中」「非表示」「再接続可能」「履歴」で絞り込めます。任意の記録へ名前を付け、ピン留めして一覧の先頭へ固定できます。最終活動日時も台帳から表示します。

cwdやファイル名をシェル文字列へ連結しません。空白、日本語、引用符、先頭ハイフン、`$()`、改行を含むパスも、URL／`currentDirectory`引数として直接扱います。

## ビルドとテスト

必要環境はmacOS 15以降、Apple Silicon、Swift 6.2系のCommand Line ToolsまたはXcodeです。初回の依存取得だけネットワーク接続が必要です。

```bash
git clone https://github.com/lutelute/finder_AI.git
cd finder_AI
./scripts/run-tests.sh
./scripts/build-workspace-app.sh
./scripts/install-workspace-app.sh   # /Applications へ反映
```

`./scripts/check-working-state.sh`は、手を動かす前にいまどこに居るのかを読むだけの確認です。**同じ作業ツリーで他のClaudeセッションが動いていないか**、git、インストール済みアプリのcommit、**FinderAIが動いているかどうか**、tmuxに残っているセッションを並べます。

このリポジトリは1つの作業ツリーを複数のセッションが共有することがあります。相手が居るときに`git add -A`を使うと、コミット前の他人の作業を巻き込んでmainへ流してしまいます（実際に起きました）。腰を据えて直すなら`git worktree add`でツリーを分けてください——ブランチの切り替えもstashも、共有しているツリーでは相手の手元を動かします。

FinderAIが動いている最中に`install-workspace-app.sh`を走らせると、使っている人の画面と生きているセッションを巻き込みます。

生成物:

- `dist/FinderAI.app`
- `dist/FinderAI.zip`

**ビルドしただけでは`/Applications`のアプリは変わりません。** 普段使うものへ反映するには`install-workspace-app.sh`を実行してください。このスクリプトは`cp -R`ではなく`ditto`を使います。`cp -R`は拡張属性をbundleへ持ち込み、`codesign --verify`が`resource fork, Finder information, or similar detritus not allowed`で失敗するためです。

通常のビルドスクリプトはReleaseビルド、SwiftTermリソース同梱、Info.plist検査、ローカル署名、`codesign --verify --deep --strict`、symlinkを維持したZIP再展開後の再検証まで行います。`FINDERAI_RELEASE=1`ではDeveloper IDとsecure timestampを必須にし、自己署名へフォールバックしません。

### 毎回フォルダアクセスを訊かれる場合

ad-hoc署名のdesignated requirementはcdhashそのものです。

```
$ codesign -d -r- "/Applications/FinderAI.app"
# designated => cdhash H"2fd174cc..."
```

cdhashはビルドごとに変わるため、macOSは各ビルドを別のアプリと見なし、TCCがデスクトップ・書類・ダウンロードの許可を破棄します。これがビルドのたびに「システム設定を開く」が出る理由です。

一度だけ以下を実行すると、requirementが証明書に紐づいて安定し、許可がビルドをまたいで残ります。

```bash
./scripts/create-signing-identity.sh   # ログインキーチェーンへ自己署名証明書を作成
./scripts/build-workspace-app.sh
./scripts/install-workspace-app.sh
```

これはローカル用の証明書をコード署名について信頼する設定であり、あなたのコード署名の信頼設定を実際に変更します。秘密鍵はこのMacから出ず、リポジトリにも入りません。`./scripts/remove-signing-identity.sh`で元に戻せます。

この証明書はDeveloper IDの代わりにはなりません。現在はDeveloper ID証明書を所有していないため、正式公開は意図的に停止します。証明書取得後は[リリース手順](docs/RELEASING.md)に従って認証情報を登録すれば、実装済みパイプラインで署名・公証・公開できます。

現在のテスト範囲と未実施項目は[検証レポート](docs/VERIFICATION_REPORT.md)、実際に触る確認手順は[実機チェックリスト](docs/MANUAL_TEST_CHECKLIST.md)を参照してください。

過去の計画と作業記録は[docs/archive](docs/archive/)にまとめてあります。その時点の記録なので、いまの実装の説明としては読まないでください。

## 安全設計

- Finderプロセスへの注入、private API、AppleScript、Finder再起動を使いません。
- Accessibility、Screen Recording、Input Monitoring、Automationを要求しません。
- ファイル処理は`FileManager`で直接行い、シェルを介しません。
- 移動・コピー・改名は上書きしません。
- フォルダを自分自身やシンボリックリンク経由の子孫へ移動する操作を拒否します。
- テレメトリ、独自ネットワーク通信はありません。Terminal内容の保存は既定で行わず、出力ログはユーザーが表示メニューで有効にした場合だけローカルに残ります。

詳しくは[設計](ARCHITECTURE.md)と[プライバシー／セキュリティ](PRIVACY.md)を参照してください。


## 既知の制約

- 配下検索は最大5,000件で、パッケージ（`.app`など）の内部までは列挙しません。
- Google Drive・OneDrive・DeepLなどがFinderの右クリックへ差し込む項目は出ません。`com.apple.FinderSync`はFinderだけがホストできる拡張ポイントで、第三者のアプリでは構造的に読み込めません。
- 同一フォルダ・同一種類のTerminalセッションは一つです。
- セッションの永続化（tmux）はオプトインで、tmuxを自動導入しません。無効時のセッションはアプリ終了・クラッシュで消えます（構成の復元提案は出ます）。
- File Provider、ネットワークボリューム、非常に大きいフォルダの一覧取得時間は提供元に依存します。一覧取得はUI外で行います。

問題がある場合は[トラブルシューティング](docs/TROUBLESHOOTING.md)を確認してください。

## アンインストール

FinderAIを終了し、`/Applications/FinderAI.app`を削除します。Finderの設定や拡張機能は変更していないため、Finderの再起動や権限削除は不要です。
