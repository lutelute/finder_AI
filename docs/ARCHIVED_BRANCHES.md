# 閉じたブランチの引き継ぎ

マージされずに閉じたPRのブランチを、**注釈付きタグ**として残してあります。
タグはブランチを消しても消えず、`git log`でも`git show`でも普通に読めます。

```bash
git tag -n99 -l 'archive/*'          # 一覧と説明
git log archive/<名前>               # コミットを読む
git switch -c 復元用 archive/<名前>   # 作業ブランチとして戻す
```

ブランチ一覧からは外しました。**中身が古いまま残っていると、うっかりそこから
派生してしまう**からです。コミット自体は上のとおり残っています。

## archive/tmux-persistent-sessions-v1

PR #3（2026-07-17、クローズ）。tmux永続セッションの**最初の実装**。

`main`には後から別実装が入りました（`3ab7f39`の1.2.0、PR #7のreconcile/recover、
1.2.1の管理パネル、1.2.2の全セッション俯瞰）。今の`main`のほうが良いのは、
tmuxへの問い合わせが非同期で、**「サーバーが居ない（=0件）」と「問い合わせに
失敗した（=不明）」を区別する**（`TmuxSessionSnapshot.isAuthoritative`）ためです。
この版は同期呼び出しで、その区別がありません。

このブランチにしかないファイル: `TmuxController.swift`、`TmuxSessionSupport.swift`、
`TmuxSessionSupportTests.swift`。

**採らなかった設計**: セッションの俯瞰を**サイドバーの1欄**として出す案
（`SessionOverviewEntry`）。`main`は独立したウインドウ（`⌘⇧T`のセッション
センター）にしました。窓を何枚も開く使い方では、サイドバーに出すと
どの窓のサイドバーにも同じものが並び、場所を食うわりに見に行く先が
分散するためです。

### この版から学んだこと（実際に痛い目を見た）

コミット`c84cdea`「GUI起動時にロケールが無い場合はUTF-8を設定」は、
**Finder/Dockから起動したアプリの子プロセスがLANG/LC_*を持たず、tmuxが
クライアントを非UTF-8とみなして日本語・絵文字・罫線を全部`_`で埋める**、
という不具合の修正でした。

このPRを閉じたときにこの修正も一緒に失われ、**2026-08-08に同じ症状が再発**。
`client_utf8=0`の実測から原因を突き止め直し、PR #32でほぼ同じ修正
（`LANG=en_US.UTF-8`の補完）を入れました。7/17に直っていたものを、
3週間後に何時間もかけて調べ直したことになります。

**教訓**: PRを「別実装に置き換わったから」と閉じるときは、そのブランチに
**置き換えとは無関係な単発の修正**が混ざっていないか確かめる。
症状が再発したら、まず閉じたブランチとPRを検索する。

## archive/app-icon-proportions

PR #1（2026-07-16、クローズ）。アプリアイコンの縦バランス調整。

**成果物は`main`に入っています**（`ded7258`で取り込み済み。`AppIcon.icns`、
`AppIcon.svg`、`AppIcon-1.2x-candidate.svg`の3つとも、`main`とblobが完全一致）。
PRを閉じたのは、マージしても差分ゼロだったためです。

このタグに残っているのは**そこへ至る過程**で、`main`では1つのコミットに
潰れています。

1. `b9adb4d` アプリアイコンの縦比率を調整
2. `e5da63e` アプリアイコンを上方向に拡張
3. `6de4fa6` アプリアイコンの縦方向をさらに拡張
4. `44f1fac` 1.2倍版アイコンを候補として保存

**アイコンを作り直すときは、この4段を見てから始めると早い**はずです。
「上方向に拡張」を2回重ねている＝1回では足りなかった、という試行が
そのまま残っています。4番目の1.2倍版は**採用ではなく候補**として置いた
もので、`main`にも同じファイルがあります（使ってはいません）。
